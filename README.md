## 👋 About Me

<img align="right" src="https://raw.githubusercontent.com/devSouvik/devSouvik/master/gif/Hi.gif" width="100">

I'm **Ashwin Selvaraj**, the founder of **Phoenix Labs** — a software studio where I design and ship AI-driven tools, security software, and full-stack products, rather than just write code for a living.

My work sits at the intersection of **Artificial Intelligence**, **Cybersecurity**, **Backend Engineering**, and **Full-Stack Development**. I like building things that run in the background and quietly do their job well: a mixing pipeline that never clips, a bot that never disconnects, a dashboard that never lies to you about your data.

Recently, my focus has shifted toward:

- 🧠 **AI-integrated systems** — products that reason, recommend, and adapt
- 🛡️ **Cybersecurity & threat detection** — behavioral analysis over static rule sets
- ⚙️ **Backend & automation** — infrastructure that scales without babysitting
- 🧩 **Developer tools & SaaS** — software built for other builders

Phoenix Labs is where all of this comes together — under one brand, with one standard: **ship it production-ready, or don't ship it.**
